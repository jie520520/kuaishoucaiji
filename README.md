# 颜阿娇 - 快手达人采集工具

一键采集快手达人广场数据，按内容标签精准筛选，自动评分排序，输出条件格式Excel。

## 快速开始

### 方式一：GUI 图形界面（推荐）

> 双击 `启动GUI.bat` 即可打开图形界面

GUI 功能：
- 可视化勾选标签（推荐标签自动选中）
- 实时进度条（当前标签 + 总进度）
- 彩色运行日志（绿=成功 / 黄=警告 / 红=错误 / 蓝=信息）
- 采集速度可调（页间延迟 / 标签间延迟 / 每页数量）
- 极速模式（0.5秒/页 + 50条/页）
- 一键停止 / 打开输出文件夹

### 方式二：命令行

> 双击 `启动采集.bat` 或手动运行：

```bash
cd "C:\Users\Administrator\Desktop\颜阿娇\快手达人采集工具"

# 推荐8个标签
python yanajiao_scraper.py --rec

# 全部37个标签
python yanajiao_scraper.py --all

# 指定标签
python yanajiao_scraper.py --tag 健康,运动,美妆

# 预览（不实际执行）
python yanajiao_scraper.py --rec --dry-run

# 交互式选择
python yanajiao_scraper.py
```

## 命令行参数

| 参数 | 说明 |
|---|---|
| `--all` | 采集全部37个内容标签 |
| `--rec` | 采集8个推荐标签 |
| `--tag 标签名` | 指定标签（逗号分隔多个） |
| `--dry-run` | 预览模式，不实际执行 |
| 无参数 | 交互式选择 |

## 工作流程

1. 打开浏览器 → 快手达人广场
2. 扫码登录（首次，后续自动登录）
3. 按标签逐批采集达人数据
4. 自动评分排序（产品契合度0-100）
5. 输出条件格式Excel文件

## 产出文件

- 所有 Excel 产物自动保存到 `采集结果/` 文件夹
- `颜阿娇_达人_{标签}_{时间}.xlsx` — 每个标签一个 Excel
- 列：序号、产品契合度、契合等级、达人名称、快手ID、粉丝数、带货品类、佣金率等
- 颜色：>=65绿色 / 50-64浅绿 / 35-49黄 / <35红

## GUI 标签页

### 标签页一：达人采集
原有功能，本次新增：
- **达人类型下拉框**：全部达人 / 直播达人 / 视频达人
- **联系方式复选框**：仅看有联系方式 / 全部达人

### 标签页二：联系方式提取（NEW）
从采集结果 Excel 中逐个打开达人详情页，点击「查看联系方式」，提取手机号和微信号。

使用步骤：
1. 先在「达人采集」标签页完成采集
2. 切换到「联系方式提取」标签页
3. 点击「自动选最新Excel」或手动浏览选择
4. 设置间隔和上限（建议每次 ≤50 人）
5. 点击「开始提取联系方式」
6. 浏览器自动逐个打开详情页提取，输出到 `采集结果/` 带 `_联系方式_` 后缀的 Excel

特性：
- 与达人采集共用浏览器登录态，无需重复扫码
- 进度自动保存为JSON，中途退出可恢复
- 每20人自动暂停15秒，避免触发风控
- 提取成功（绿）/ 失败（红）双色标注
- 支持命令行独立运行：`python extract_contacts.py --input xxx.xlsx --max 30`

### 联系方式提取 CLI 用法

```bash
# 自动选最新采集结果
python extract_contacts.py

# 指定文件，最多30人
python extract_contacts.py --input 采集结果/颜阿娇_达人_健康_20260713_124840.xlsx --max 30

# 单达人测试（验证提取是否正常）
python extract_contacts.py --id 535256404
```

## 特性

- 图形界面 + 命令行双模式
- 双标签页：达人采集 + 联系方式提取
- 断点续传：已采集标签自动跳过
- 登录态持久化：一次扫码，长期有效
- 限流自动重试：指数退避，最多8次
- 仅采有联系方式的达人（hasContact=1）
- 采集速度可调（GUI 中设置）
- 极速模式（0.5秒/页 + 50条/页）
- 联系方式：手机号+微信号纯文本提取，已实测通过
